# Repository Instructions

- Preserve the `skills/<domain>/<skill>/` taxonomy.
- Read a skill's `SKILL.md` before using or modifying that skill.
- Load referenced files only when the task requires them.
- Keep shared guidance in `shared/`; do not duplicate it across skills.
- Give every skill YAML frontmatter containing only `name` and `description`.
- Keep each skill's `agents/openai.yaml` interface metadata aligned with its `SKILL.md`.
- Use lowercase, hyphenated skill directory names that match the frontmatter `name`.
- Keep personal or licensed binary assets as placeholders until the owner supplies them.
- Validate scripts directly after changing them.
