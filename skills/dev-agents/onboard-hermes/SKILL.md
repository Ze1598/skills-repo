# Optional Hermes Adapter

Hermes is not the default or a requirement. For repository contracts and migration planning, use
`../kanban-agent-pipelines/SKILL.md` and `../agent-self-learning/SKILL.md` instead.
This adapter does not override canonical role definitions, review modes, feedback eligibility,
learning-review termination, evidence retention or the main session's coordination responsibilities.

When Hermes is explicitly selected, read `references/onboarding.md`. Verify commands and capabilities
against that installation before using them. Existing deployed profiles are derived copies; update them
only within the user's deployment authorization. Do not infer authorization from repository edits.
